# Functional Treat

A simple Python menu-driven program demonstrating the use of **functions**, **recursion**, **lambda expressions**, **map()**, **filter()**, **sorting**, **statistics**, and **2D lists**.

## 📌 Features

- Input a 1D list of integers
- Calculate factorial using recursion
- Filter data using `filter()` and `lambda`
- Square all elements using `map()` and `lambda`
- Find minimum, maximum, and average of the dataset
- Sort data in ascending and descending order
- Display and sort a predefined 2D list
- Menu-driven interface

## 🛠️ Functions Used

### `input_data()`
Accepts a list of integers from the user.

### `factorial(n)`
Computes the factorial of a number using recursion.

### `filter_data()`
Filters elements from the dataset using `filter()` and a lambda function.

### `square_data()`
Squares each element using `map()` and a lambda function.

### `statistics()`
Returns:
- Minimum value
- Maximum value
- Average value

### `sort_data()`
Sorts the dataset in:
- Ascending order
- Descending order

### `display_2d()`
Displays a predefined 2D list and prints its sorted rows.
